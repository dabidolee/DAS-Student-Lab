# Release Checklist

- [ ] Replace all `example.invalid` URLs.
- [ ] Confirm final package name on PyPI and GitHub.
- [ ] Choose and document the code license.
- [ ] Confirm data access and redistribution terms.
- [ ] Complete dataset/software citations.
- [ ] Obtain scientific-language review.
- [ ] Run `python -m pytest`.
- [ ] Run `python -m ruff check .`.
- [ ] Run `python -m build`.
- [ ] Install the built wheel in a new environment.
- [ ] Execute every tutorial from beginning to end.
- [ ] Confirm default download size and low-resource failure behavior.
- [ ] Complete novice user testing and record revisions.
- [ ] Update `CHANGELOG.md` and `CITATION.cff`.
- [ ] Publish to TestPyPI before PyPI.
- [ ] Tag version 0.1.0 only after all checks pass.
