# Tutorials

The first script is executable now. The remaining tutorials should be written by David after the data-access and teaching designs are reviewed.

Planned sequence:

1. `01_inspect_synthetic_data.py` — understand dimensions, sampling, span, and memory.
2. `02_from_array_to_visible_signal.py` — compare transparent preprocessing choices using established tools.
3. `03_design_a_small_project.py` — create a reproducible manifest and experiment question.

Each tutorial must:

- state the learning objectives;
- distinguish synthetic and measured data;
- explain units at first use;
- ask the learner to predict before revealing key output;
- record parameters, package versions, and citations;
- avoid unsupported biological or physical conclusions.
